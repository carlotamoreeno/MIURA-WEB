Demo visual MIURA MVP 0.1

Recorrido guiado para explicar la deuda técnica en lenguaje de negocio.

Este guion visual usa pantallas capturadas de MIURA Web App para mostrar el flujo completo de usuario: iniciar una evaluación local, completar evidencia, leer resultados ejecutivos y técnicos, exportar un informe, gestionar datos locales y consultar la metodología o la conversación de apoyo.

24recursos visuales
10rutas MVP cubiertas
3comprobaciones móviles
0persistencia de datos de usuario en servidor
Manual de usuario paso a paso

Además del storyboard visual, la demo incluye una guía práctica para usar MIURA: creación, asistente, cuadro de mando, informe, ajustes, chat RAG y preguntas frecuentes.

Mapa del flujo de producto

La demo sigue una ruta principal de decisión y después abre las pantallas de apoyo.

El orden refleja el modelo mental que necesita quien mira la demo: entender por qué existe MIURA, introducir contexto local, recoger evidencia, interpretar resultados, exportar el artefacto y usar el conocimiento de apoyo.

Hueco conocido de captura

El RAG está implementado, pero la recuperación en vivo devolvió fuentes insuficientes en esta captura local, por lo que el guion visual no fabrica una respuesta con citas. La comprobación posterior confirmó que la pregunta "que es PDI" recupera citas con el umbral aceptado del proyecto; la captura se hizo con una configuración local más estricta. Las pantallas de conversación documentan el estado seguro sin fuentes y los controles de contexto mínimo de evaluación.
